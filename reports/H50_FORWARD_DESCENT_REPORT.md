# H50 forward-descent technical report

The complete canonical Version 1.0 report and its large certificate/frontier corpus are preserved in the frozen Zenodo release:

**https://doi.org/10.5281/zenodo.23357210**

This GitHub repository keeps the H50 search/continuation/verifier code and compact result/check summaries under `code/h50_descent/` and `data/h50_descent/`.

Canonical result: the preserved computer-assisted argument gives a lower-natural-density bound

```text
Q50 ≈ 0.8695739413707237
```

for starts that fall below their original value within 50 moves. It is **not** a six-cycle capture percentage, **not** a probability that the conjecture is true, and **not** a universal convergence proof.
