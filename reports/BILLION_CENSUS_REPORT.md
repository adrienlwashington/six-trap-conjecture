# Billion-census technical report

The complete canonical Version 1.0 report is preserved in the frozen Zenodo release:

**https://doi.org/10.5281/zenodo.23357210**

This GitHub repository keeps the exact retained execution source in `code/census/census_executed.cpp`, the hardened reusable census in `code/census/census.cpp`, the independent verifier/audit code, and compact machine-readable outputs under `data/census_billion/`.

Canonical finite result: every integer from **2 through 1,000,000,000 inclusive** — **999,999,999 starts** — was classified into the six registered cycles, with zero unclassified starts and zero cap hits. This is finite computational evidence, **not a general proof**.
