# Machine-readable evidence

This GitHub repository keeps the compact machine-readable outputs needed for orientation and inspection. The **canonical frozen Version 1.0 archive** at [Zenodo DOI 10.5281/zenodo.23357210](https://doi.org/10.5281/zenodo.23357210) remains the complete release record.

- `census_billion/` contains compact saved outputs from the 2..1,000,000,000 census. The larger selected `verification_targets.csv` corpus remains in Zenodo.
- `census_verification/` contains compact independently recomputed classifications/trajectory summaries.
- `h50_descent/` contains result status, continuation data, compact check summaries, and the cover summary. The large compressed `certificates.jsonl.gz` and `frontier.jsonl.gz` remain in Zenodo.

The omission of those bulky archival files from GitHub does not change Version 1.0; GitHub is the living technical home, while Zenodo is the immutable canonical release.
